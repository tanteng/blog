# Stock Analysis Report Skill 设计规格

## 概述

基于 TradingAgents-CN 的多 Agent 股票分析框架，构建一个 Skill，用户粘贴股票分析文本后，自动生成完整的 PDF 分析报告。

## 输入

- **方式**：用户直接粘贴文本数据
- **格式**：股票分析报告的文字内容（可能是多种格式的报告文本）

## 处理流程

### 1. 数据理解
解析用户粘贴的文本，识别其中包含的信息维度：
- 基本面数据
- 技术面数据
- 新闻资讯
- 社交媒体情绪
- 其他分析内容

### 2. 多 Agent 分析框架

使用以下 13 类 Agent 的 prompt 模板进行分析：

| Agent | 职责 | 输出 |
|-------|------|------|
| 多头分析师 | 构建买入论证 | 看涨论点 |
| 空头分析师 | 构建卖出论证 | 看跌论点 |
| 市场分析师 | 技术分析 | 技术指标分析 |
| 基本面分析师 | 财务数据分析 | 估值分析 |
| 新闻分析师 | 新闻影响评估 | 新闻影响 |
| 社交媒体分析师 | 情绪分析 | 情绪报告 |
| 研究经理 | 辩论裁决 | 投资建议 |
| 交易员 | 交易决策 | 具体计划 |
| 激进风险辩手 | 高风险视角 | 激进论点 |
| 保守风险辩手 | 低风险视角 | 保守论点 |
| 中性风险辩手 | 平衡视角 | 中性论点 |
| 风险经理 | 风险决策 | 最终风险评估 |
| 反思系统 | 经验总结 | 学习要点 |

### 3. 报告生成
整合所有分析结果，生成结构化 HTML 报告。

## 输出

- **格式**：PDF 文件
- **生成方式**：在 OpenClaw 服务器 (43.134.180.240) 上生成
- **返回**：下载链接

## PDF 报告结构

1. 股票基本信息
2. 多空辩论结果
3. 各维度分析（技术/基本面/新闻/情绪）
4. 投资建议 + 目标价
5. 风险评估结果
6. 总结

## 技术方案

### 服务器端
- WeasyPrint 用于 HTML 转 PDF
- 中文字体支持（思源黑体/Noto Sans CJK）
- Python 3 环境

### 文件结构
```
stock-analysis-report/
├── skill.md          # 主 skill 文件
├── report.html       # HTML 报告模板
├── generate_pdf.sh   # PDF 生成脚本
└── fonts/            # 中文字体目录
```

### 部署流程
1. 安装 WeasyPrint 和依赖
2. 配置中文字体
3. 上传 HTML 模板和脚本到服务器
4. Skill 调用脚本生成 PDF

## 依赖

- **服务器**：OpenClaw (43.134.180.240)
- **工具**：WeasyPrint, Python 3, 中文字体
- **网络**：可访问下载链接

## 限制

- 用户需自行确保粘贴数据的完整性和准确性
- PDF 生成依赖服务器资源
