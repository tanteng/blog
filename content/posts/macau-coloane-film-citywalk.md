去过澳门好多次了，但还没去过路环岛，早就听说是个很休闲的去处，于是在一个天气晴好的下午出发。过关后终于不是坐"发财车"了，而是坐公交巴士到路环市区，逃离澳门的纸醉金迷。

<!--more-->

这次没有带专业的相机，只带了一台半格胶片相机。

📷 设备：Pentax 17

🎞️ 胶卷：Fuji C400

出发之前用 AI 规划了一下行程，简直太方便了。但我没完全按照行程走，而是到了之后很随意决定去哪，不必去到每个地方。

推荐一个轻松版 Citywalk 路线：

📍 路环市区站下车 ➔ 🥚 安德鲁饼店总店 ➔ ⛪️ 圣方济各教堂 ➔ 📚 路环图书馆 ➔ ☕️ 汉记手打咖啡 ➔ 🌊 黑沙海滩看日落

除了黑沙沙滩另外坐车，其他地方都集中在不大的一个区域，所以很轻松。

{{< figure class="post-img" src="https://assets.tanteng.space/photo-Krd1NjEuPql7yMPE.jpeg?imageMogr2/auto-orient/thumbnail/1000x/format/webp/quality/88/interlace/1" caption="安德鲁蛋挞店前" loading="lazy" >}}

下车旁边就是有名的"安德鲁饼店"总店，有很多人在排队，买两个蛋挞尝尝。

{{< figure class="post-img" src="https://assets.tanteng.space/photo-KdeDjQx3ONsROAyk.jpeg?imageMogr2/auto-orient/thumbnail/400x/format/webp/quality/88/interlace/1" caption="安德鲁蛋挞" loading="lazy" >}}

口感和味道可以说跟肯德基一模一样。

上面这张是张曝光废片——当时相机拿在手上撞到栏杆，后盖弹开了，胶卷暴露出来，吓得我赶紧合上，还好曝光的废片不多。

从安德鲁饼店往左走就是十月初五马路，圣方济各教堂，路环图书馆都在这个方向。


{{< figure class="post-img" src="https://assets.tanteng.space/photo-O3s4WQrMLqY99KdR.jpeg?imageMogr2/auto-orient/thumbnail/400x/format/webp/quality/88/interlace/1" caption="圣方济各教堂，可入内参观" loading="lazy" >}}

{{< figure class="post-img" src="https://assets.tanteng.space/photo-npeP1EJJ7KiVH1fv.jpeg?imageMogr2/auto-orient/thumbnail/1000x/format/webp/quality/88/interlace/1" caption="路环图书馆" loading="lazy" >}}

路环图书馆也可以入内参观。好像闯进了韦斯·安德森的电影里。

{{< figure class="post-img" src="https://assets.tanteng.space/photo-Gjm8Ia35jZFAc9Rp.jpeg?imageMogr2/auto-orient/thumbnail/1000x/format/webp/quality/88/interlace/1" caption="彩色的房子" loading="lazy" >}}

胶片相机每次要手动过片，拍完不能立马看，只有洗出来才能看到效果，就增加了一种期待感，还有延迟满足感。

胶片相机不急于出片，不急于发社交平台，能让你慢下来，一卷胶卷有时可能要拍几个月。另外，它的色彩也是非常独特的，很真实复古。

胶片有时候的噪点，不清晰，还会曝光，它的不完美本身就是独特之处，偶尔不完美一下也没关系。

还有很重要的一点，它重量很轻，放口袋就好了，不用背着一个包。

{{< figure class="post-img" src="https://assets.tanteng.space/photo-trIF7UPnBbwDeTCv.jpeg?imageMogr2/auto-orient/thumbnail/400x/format/webp/quality/88/interlace/1" caption="汉记手打咖啡" loading="lazy" >}}

当地有名的汉记手打咖啡，口感还不错。

{{< figure class="post-img" src="https://assets.tanteng.space/photo-yv52MnKBfbnfq10q.jpeg?imageMogr2/auto-orient/thumbnail/400x/format/webp/quality/88/interlace/1" caption="夕阳下的小径" loading="lazy" >}}

僻静的小径，夕阳西下。

{{< figure class="post-img" src="https://assets.tanteng.space/photo-v9ddGDjc58eyUtmW.jpeg?imageMogr2/auto-orient/thumbnail/1000x/format/webp/quality/88/interlace/1" caption="路环码头" loading="lazy" >}}

回到公交站点坐车去黑沙滩，在途中也看到很美的海边风景，时间充足的话，可以沿着海边走到黑沙滩，但下次再来吧。

{{< figure class="post-img" src="https://assets.tanteng.space/photo-0oRmKXRMXIpuU0j3.jpeg?imageMogr2/auto-orient/thumbnail/1000x/format/webp/quality/88/interlace/1" caption="黑沙海滩" loading="lazy" >}}

沙滩上游客不是很多。

{{< figure class="post-img" src="https://assets.tanteng.space/photo-m71nxo5ZtPT1kRtm.jpeg?imageMogr2/auto-orient/thumbnail/1000x/format/webp/quality/88/interlace/1" caption="黑色沙子" loading="lazy" >}}

第一次见到这种黑色沙滩。

拍到这里，刚好一卷胶卷拍完了，胶卷回片装进暗盒里。再坐车顺便去官也街逛逛。

原来澳门不只有金碧辉煌，还有安静舒适的徒步路线，和每按一下快门时的期待。
